# Portfolio Version 2

Version 2 introduces a more distinctive, premium visual system while preserving
the multilingual content, navigation, Sanity integration, and responsive
structure from the original portfolio template.

## Design updates

- Replaces hard-edged interface groups with separated, rounded material surfaces.
- Adds an Engineered Glass treatment with restrained lighting, depth, grain, and
  hover movement.
- Introduces softer capability and project cards with capsule-style metadata.
- Refines the header with a floating navigation surface and pill language selector.
- Reworks project links as tactile controls without generic underline-and-arrow
  styling.
- Rebuilds the journey preview as individual floating cards.
- Adds a dimensional footer dock, sculptural GH signature, and distinctive
  LinkedIn and GitHub profile capsules.
- Updates the visible identity and authorship credit to Gabriel Humbert.

## Status

This branch is a saved design version. Publishing it to GitHub does not deploy it
to the production website.
